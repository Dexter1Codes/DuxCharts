# AI-Driven Intraday Market Intelligence

Capstone project, Bennett University. An educational market-intelligence
platform for NSE instruments. Research and simulation only: it places no
orders and gives no buy or sell advice.

## Structure

    analysis/   Python. Ingestion, indicators, similarity search, CAS statistics.
    server/     Node + Express REST API over MongoDB.
    web/        React dashboard.

## Status

Data layer complete and verified. See `docs/` for the Milestone-1 proposal
and the data report.
